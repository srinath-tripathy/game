# Catch My Heart

A heart-catching game for couples, built with [Phaser 4](https://github.com/phaserjs/phaser), React and Vite.

Move the basket with the arrow keys, mouse or finger. You have 60 seconds to catch as many hearts as you can — gold hearts are worth more, while broken hearts, clouds and devils take hearts away. When the round ends, share your score with your partner as a link and challenge them to beat it.

## Commands

| Command | Description |
|---------|-------------|
| `npm install` | Install dependencies |
| `npm run dev` | Start the dev server at http://localhost:8080 |
| `npm run build` | Build for production into `dist` |

## Deploying

Every push to `main` builds the game and publishes it to GitHub Pages (see `.github/workflows/deploy.yml`). One-time setup on GitHub: Settings → Pages → Source: "GitHub Actions".
